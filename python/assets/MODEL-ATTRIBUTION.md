# Kokoro-7M-Distill ONNX

The ONNX model was supplied with this project. The matching English `af_msa` voice pack and vocabulary configuration are from the upstream repository:

- Model: [oddadmix/Kokoro-7M-Distill-ONNX](https://huggingface.co/oddadmix/Kokoro-7M-Distill-ONNX)
- License: Apache License 2.0, included in `LICENSE-2.0.txt`
- Inference sample rate: 24 kHz

The model and voice files run locally. A network connection is not used for document conversion.
